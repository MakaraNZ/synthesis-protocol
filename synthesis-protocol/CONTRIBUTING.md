## Before You Contribute

Read these files first:

1. `README.md` — what this protocol is
2. `core/north_star.txt` — the governing purpose
3. `governance/sacred_pou_governance.yaml` — the constitutional laws
4. `docs/SOVEREIGNTY.md` — the ethical covenant
5. `GOVERNANCE.md` — who decides what

This is not bureaucracy. These documents take 15 minutes to read. If you contribute without reading them, your contribution will likely miss the constitutional context.

## Types of Contribution

### Tier 1 — Documentation, Examples, Tooling (open)
Examples, additional reference implementations, translations of documentation into other languages, additional SGIL entry templates, Pātaka integration examples, improved code comments.

No special permission required. Follow the pull request process below.

### Tier 2 — New Components (discussion first)
New files that extend the protocol — additional interoperability schemas, new governance documentation, platform-specific implementation guides.

Open an issue first. Describe the component, its constitutional grounding, and which Pou it serves. Wait for acknowledgement before building.

### Tier 3 — Constitutional Files (Peter Makara's direct review required)
Any modification to the thirteen constitutional files listed in `GOVERNANCE.md`.

Open an issue with full constitutional justification. Do not submit a pull request without prior discussion.

---

## Pull Request Process

1. Fork the repository and create a branch with a descriptive name
2. Make your changes
3. In your pull request description, answer:
   - What does this contribution add or improve?
   - Which Pou does it honour?
   - What external knowledge did you draw from, and is it attributed? (Pou I)
   - Does it touch any constitutional file? If yes, is there an open issue?
4. Submit

---

## Attribution Standard

Pou I — Whakapapa as Anchor. Every idea has a lineage. If your contribution draws from a specific thinker, tradition, or framework, attribute it. This is not a formality. It is the practice that keeps the architecture honest.
