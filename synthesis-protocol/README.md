## What This Is

The **Synthesis Sovereign Intelligence Ecosystem** is a constitutional AI governance framework. It provides a complete architecture for sovereign intelligence: constitutional laws, a governance scan, a digital whakapapa ledger, a biometric intelligence layer, and a six-phase runtime loop — all governed by a single North Star.

**Locked definitions — these do not vary:**
- `Synthesis` = sovereign operating intelligence
- `SIS` = Synthetic Intelligence System
- `HEP` = Human Enhanced Performance

## Quick Start

```bash
git clone https://github.com/petermakara/synthesis-protocol
cd synthesis-protocol
python reference/synthesis_reference_runtime.py
```

Or install via pip:
```bash
pip install synthesis-protocol
```

Or via npm:
```bash
npm install @synthesis/protocol
```
